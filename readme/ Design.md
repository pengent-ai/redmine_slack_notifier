# redmine_slack_notifier

RedmineからSlack通知のためのプラグインです

* 新しい`Incoming Webhooks`の対応しました
* `chat.postMessage`については対応予定です


## 機能一覧


| 分類 | 項目                 | 内容                                  |
| ---- | -------------------- | ------------------------------------- |
| 通知 | チケット作成時の通知 | プロジェクト毎にチャンネル通知する    |
|      | チケット更新時の通知 | プロジェクト毎にチャンネル通知する    |
| 設定 | Slack用の通知URL     | Slack用の通知URL プロジェクト毎の設定 |

## 今後の見込み

機能リクエスト、または必要性に応じて`chat.postMessage`にも対応していく予定です。
現時点では対応していません。
