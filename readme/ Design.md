# redmine_slack_notifier

RedmineからSlack通知のためのプラグイン

## 機能一覧

| 分類 | 項目                 | 内容                                  |
| ---- | -------------------- | ------------------------------------- |
| 通知 | チケット作成時の通知 | プロジェクト毎にチャンネル通知する    |
|      | チケット更新時の通知 | プロジェクト毎にチャンネル通知する    |
|      | チケット削除時の通知 | プロジェクト毎にチャンネル通知する    |
| 設定 | Slack用の通知URL     | Slack用の通知URL プロジェクト毎の設定 |
